# WoW Forever addons

[Open the addon guide](https://damos1212.github.io/wow-addon-list/)

Damos1212’s list of 40 addons for leveling, gear, and UI in WoW Forever. The guide groups them by priority and includes download counts and direct CurseForge links.

- Use the search box to find an addon or feature.
- Click a screenshot to enlarge it. Three entries use labeled illustrations.

## About the site

GitHub Pages serves `index.html` from `main`. The page contains its own styles, scripts, and images, so you can also download the file and open it locally in a browser.

Screenshots come from the linked addon projects. The image viewer links to each screenshot’s source.

The banner was generated for the guide with ImageGen. The prompt depicted a scarred dire wolf beside an orc stronghold, with Durotar dust, a ragged red war standard, and an ember-lit sky. The WebGL animation follows your device’s reduced-motion setting.
