# WoW Forever addons

[Open the addon guide](https://damos1212.github.io/wow-addon-list/)

Damos1212’s list of 40 addons for leveling, gear, and UI in WoW Forever. The guide groups them by priority and includes download counts, setup notes, and direct CurseForge links.

- Use the search box to find an addon or feature.
- Click a screenshot to enlarge it. Three entries use labeled illustrations.

## About the site

GitHub Pages serves `index.html` from `main`. The page contains its own styles, scripts, and images, so you can also download the file and open it locally in a browser.

Screenshots come from the linked addon projects. The full-size viewer links to each screenshot’s source. Download counts are CurseForge project totals across versions, checked November 3, 2026.
